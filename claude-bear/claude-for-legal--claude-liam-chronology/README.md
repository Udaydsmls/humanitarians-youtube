# Claude, Chronology.

A legal matter draws its facts from a stack of documents — emails,
invoices, deposition transcripts — each one mentioning dates on its own.
The natural move is to pull every date out and lay them in order, but two
different documents often describe the exact same event on the exact
same day, in different words — a plain list of every mention counts it
twice. Chronology building extracts every dated event from the declared
sources, then collapses duplicates: however many documents name it, one
event becomes one entry. Watch the anchor: a late payment named in an
email, an invoice, and a deposition transcript, all the same day — one
entry, not three. What isn't fixed is the tag on it: for a matter built
on breach of contract, that payment is central, tagged high; for a
different matter built on a different theory, the same payment barely
registers, tagged low. A low tag doesn't mean the event is wrong or
missing — it means this matter's theory doesn't turn on it. And one
entry instead of three doesn't mean only one document mentioned it — it
means every mention pointed at the same day.
