# Claude, Cease Desist. — The Cease-and-Desist Skill

When Claude drafts a cease-and-desist letter, it isn't making the call on
its own — it's reading a Skill. A Skill is a folder with one instruction
file, SKILL.md, written in plain language: no hidden logic, no freeform
judgment. Claude reads it, then executes each step in order — read the
file, execute the steps, return the result — linear, no branching unless a
step says otherwise. One rule inside this particular Skill is specific: the
internal draft, the pre-send brief, and the triage memo are all marked as
attorney work product, but the letter that actually goes out isn't, because
it's written to be read by the other side, not filed away internally.
Claude isn't deciding what belongs in the letter. It's following the
SKILL.md, one step at a time, and only doing what that file says.

## Deliberately not claimed

mechanism (a named folder, one instruction file, a linear pipeline, one
specific header rule) holds regardless of the facts involved. No claim that

— Claude follows the file, and the file is the limit.
