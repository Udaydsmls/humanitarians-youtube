# Claude, Built — Building Your Own Plugins

None of the official Claude plugins fit how you actually work? You can build
your own. A plugin bundles up to four things — skills, commands, connectors,
and subagents — into one folder of plain text. You don't write code or edit
configuration files: a guided builder assembles it from a conversation,
sorting what you describe into those same four parts. This walks the whole
loop — why it's worth it, what's inside, how you build one, what to build it
for, and how to keep it evolving once it works.

## Deliberately not claimed

No plugin count and no platform URL — the official catalog and the wider
directory both grow, so the reel names neither a number nor a link that
would date. No named third-party tools — "your pricing spreadsheet," "a
specific folder" stand in for whatever you actually use. The building tool
is named only by what it does — "a guided builder, itself a plugin you
install" — not a versioned product string.
