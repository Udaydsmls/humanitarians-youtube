# CARRY-OUT

> Claude isn't finding answers — it's generating the next most useful thing to say,
> shaped by everything Anthropic taught it to care about.

Test: if someone repeats only this in a meeting next week, is it still true? Yes —
it compresses the key distinction (generation vs. retrieval) without overstating it.

**Wrong guess this defeats:** "Claude is a search engine — it retrieves answers from
somewhere." The carry-out replaces that frame with the correct one: Claude generates,
and the shape of what it generates came from training, not from a live lookup.
