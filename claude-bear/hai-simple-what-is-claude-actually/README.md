# What is Claude, actually?

Most people who use Claude think of it as a smart search engine — something
that retrieves the right answer. It isn't. There is no index, no lookup, no
answer waiting on a shelf. Every response is generated from scratch, token by
token, shaped by what Anthropic taught it to care about. That difference turns
out to matter in ways that aren't obvious until you see the mechanism.

## One flag, stated in the video

Plausible is not the same as verified. Claude generates the most useful next
token given its training — it does not look up ground truth before each word.
The video says this out loud rather than letting "it predicts well" slide into
"it always gets it right."
