# Claude, Case Brief.

Claude picked up a skill called case-brief — did it actually learn case
law? No. A "skill" is a folder holding one file, SKILL.md, that Claude
reads before it starts and then follows step by step, in order. Delete the
folder and Claude forgets no case law, because there was nothing to learn —
it just stops following that one routine. That makes a skill a
specification, not a new power: the payoff is the same structure, every
brief — facts, issue, rule, conclusion; the limit is anything the file
never wrote down. And watching Claude produce a clean brief, or a messy
one, proves nothing on its own about whether it actually understood the
case.

## Deliberately not claimed

This reel does not describe what the case-brief skill's own SKILL.md
specifically instructs — that file lives in a legal-clinic collection not
reachable from this build, and the source script this reel redoes never
filled in that detail either (its own beat sheet still carries an unfilled
`>` placeholder in four spots). Rather than invent a legal-specific
procedure, this reel uses "case-brief" only as the named example of a
skill-shaped folder (one file, SKILL.md), plus the well-known, generic
shape of a legal case brief itself (facts, issue, rule, conclusion), and
sticks to what's true and generic about how any Claude skill works: a
folder Claude reads before it acts, executed step by step, with a payoff
and a limit. See BUILD-LOG.md for the full account.
