# CARRY-OUT

> A blank chat and an empty project behave the same way. Claude only sharpens
> once you feed it the documents you'd otherwise keep re-explaining.

Test: if someone repeats only this in a meeting next week, is it still true?
Yes — it compresses the source's key distinction (context is the variable,
not the container) without overstating it.

**Wrong guess this defeats:** "My Claude answers are generic because the model
isn't smart enough — I need a cleverer prompt or a better model." The
carry-out replaces that frame with the source's actual mechanism: default
sessions start blank regardless of model quality; the fix is what you load,
not how you ask.
