## S05 — ANCHOR PAYOFF (the concrete action)

*(THE ANCHOR RETURNS — same three documents, now loading into a project.)*

## S06 — Both Directions (A: holds)

When the project is genuinely loaded — the real documents, the actual history —
the model stops defaulting to generic and starts answering like it knows your work.

## S07 — Both Directions (B: flips)

*(Mirrors S06's layout — empty project, not loaded.)*

An empty project doesn't count. One you create but never load behaves exactly like
a blank chat — the label changed, the context didn't. Extra files you never open
don't help either.
