# Claude, Client Comms Log.

Claude picked up a skill called client-comms-log — did it actually start
remembering your clients? No. A "skill" is a folder holding one file,
SKILL.md, that Claude reads before it starts and then follows step by
step, in order. Delete the folder and Claude forgets no client history,
because there was nothing stored between runs to forget — it just stops
following that one logging routine. That makes a skill a specification,
not a memory: the payoff is the same log structure, every entry — date,
contact, channel, summary; the limit is anything the file never wrote
down. And watching Claude produce a clean log entry, or a messy one,
proves nothing on its own about whether it actually understood the call.
