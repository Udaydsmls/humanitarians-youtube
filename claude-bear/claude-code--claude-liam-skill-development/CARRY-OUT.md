# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A skill isn't something you ask Claude to remember — it's a file whose
> description has to do the finding, and everything inside it only loads
> once that description matches.**

## The wrong guess it defeats

That you can get the same repeatable behavior by just telling Claude, in
conversation, to always handle a task your way ("always rotate my PDFs like
this"). That instruction lives in the conversation — once it scrolls out of
context or a new session starts, it's gone. A skill lives in a file whose
name and description sit in front of every conversation, visible whether or
not you ever mention it again, and the rest of the skill — the body, and
any scripts, references, or output files — only loads once that description
actually matches what's being asked.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (a skill is a
findable, packaged file, not a conversational request) without overstating
what good phrasing guarantees: "the description has to do the finding"
also covers the source's real gotcha — a vague description doesn't fire
reliably, and a script pasted straight into the body defeats the very
loading model the file is supposed to use.

## What it deliberately does not say

- Not a verdict on whether the 1,500–2,000 word target should have been a
  hard limit, or whether the skill's own documentation should have
  explained how the trigger match actually works (Teardown territory) —
  Plain states the mechanism and the failure mode, and stops.
- Not a claim that every skill needs all three resource folders — scripts,
  references, and assets are each optional, and the reel never implies a
  skill is incomplete without them.
- Not a claim that Claude reads the whole skill on every turn — only the
  name and description are always in context; the body and resources load
  conditionally, and the reel keeps that distinction intact.
