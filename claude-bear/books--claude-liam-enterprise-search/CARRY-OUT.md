# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **Enterprise search doesn't give Claude new access — it gives you faster
> reach over what you can already see, because it reads what's actually
> written, not just what it's named.**

## The wrong guess it defeats

That "searching everywhere" means Claude reaches beyond what you personally
have permission to open — or, on the flip side, that if your own file search
already came up empty, the answer isn't there. Neither is true: enterprise
search is bounded strictly by your existing access, and it finds things
regular search misses only because it reads content instead of matching
filenames.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (faster reach over
existing access, not new access) without overstating what the tool can see
or promising it replaces documenting decisions in the first place.

## What it deliberately does not say

- Not a claim that it searches "everything" — only sources you've connected,
  and only content you could already open yourself.
- Not a claim that indexing is instant — first-time indexing takes a while;
  after that, searches are fast.
- Not a substitute for writing things down — the payoff compounds only if
  decisions get documented as they're made.
