## Description

"My company already wrote this down somewhere — can Claude just find it?" Yes, if you
turn on enterprise search — but not by searching everywhere. It reads what's actually
inside your documents instead of matching filenames, and it's bounded strictly by your
own existing access.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: why normal search misses the answer even when it's written down (a file
named "Q3 notes" that actually holds the reason you switched payment processors); how
enterprise search reads content instead of filenames across your drive, wiki, folders,
and chat at once, from one plain-language question; how it pulls the found content
straight into the conversation so Claude reasons from your own decisions instead of
generic best practice; and the one line that matters most — it never reaches anything
you couldn't already open yourself, it just reaches it faster.

Try it yourself — the video ends with a paste-ready prompt for setting up enterprise
search for your own team in Claude today.
