# When Does an AI Handoff Actually Finish?

Handing a task to Claude and getting a finished-looking result back feels
like the job is done. It isn't — not yet. A working handoff has three
parts: a scope (exactly what's being asked), a boundary (the point where a
human has to confirm before anything counts as final), and a record of
what changed. Watch the anchor: a contract redline comes back from Claude
with every changed clause marked in the margin — marked, not accepted.
Only once a lawyer checks each mark against the record and signs off does
it become final. Silence isn't a signature, and a heavily rewritten first
pass isn't a failure either — both can be the handoff working exactly as
intended.
