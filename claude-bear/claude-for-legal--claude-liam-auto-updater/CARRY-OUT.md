# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **A Skill's SKILL.md is the whole program. Claude follows it exactly —
> reliable inside what's written, blind past its edge.**

## The wrong guess it defeats

That a Skill named `auto-updater` runs on some opaque, built-in capability —
logic baked into the model itself, the way "auto" suggests something
happening automatically and invisibly. It doesn't. The logic is baked into
a plain-text file, `SKILL.md`, that Claude reads before it acts and follows
step by step. Delete a step from that file, and that step simply doesn't
happen — nothing hidden fills the gap. The file is the program, not a
hint the model works from.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (the file is the
program, not a suggestion the model improvises around) and it also carries
the guarantee's edge in the same breath: "reliable inside what's written,
blind past its edge" is true of every Claude Skill, not just this one.

## What it deliberately does not say

- **Not a claim about what `auto-updater` specifically updates.** The
  source's own narration never actually states this (see QUESTION.md's
  "source defect" note — three of seven source beats carry an unfilled
  template placeholder where that specific content should have been, and
  the real `SKILL.md` lives on a machine this build can't reach). This
  reel states only what's generically true of any Claude Skill's
  mechanism, using `auto-updater` as the name, not as a source of invented
  specifics.
- **Not a verdict on the design.** The source's B03 called this "the
  Teardown moment" and framed it as "what it gets right / what it bites" —
  Teardown language. Plain keeps the same underlying mechanism (repeatable
  inside the spec, unsupported outside it) but states it as a boundary,
  not a critique of whoever wrote the file.
- **No accusation that the source's broken template was concealing
  something.** It reads as an ordinary batch-build substitution bug, and
  the reel treats it as one.
