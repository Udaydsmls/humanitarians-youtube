# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **executive-briefing doesn't notice what you need — it matches a fixed
> list of trigger words, and the moment your request skips that list, the
> skill stays quiet, no matter what you actually meant.**

## The wrong guess it defeats

That Claude senses on its own when something needs executive-level polish —
some built-in judgment call. It doesn't: `executive-briefing` is one file,
`SKILL.md`, and per the source's own description it activates only "when
user mentions 'executive', 'briefing', 'C-suite', 'board', 'leadership', or
'presentation.'" Ask for the identical outcome in words that miss that list
— "make this shorter for my boss" instead of "turn this into a board
presentation" — and the skill never fires, even though the memo and the
intent are the same.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (activation is a fixed
word match, not a read of intent) without overstating what the skill can or
can't produce once it does fire.

## What it deliberately does not say

- Not a claim that Claude never uses judgment elsewhere — only that *this*
  skill's switch is a literal word match, per its own SKILL.md.
- Not a verdict on whether keyword-triggered activation is a good or bad
  design (Teardown territory) — Plain states the mechanism and the
  boundary, and stops.
- Not that every Skill activates this way — `executive-briefing`'s trigger
  list is the worked example, not a universal claim about every Skill.
