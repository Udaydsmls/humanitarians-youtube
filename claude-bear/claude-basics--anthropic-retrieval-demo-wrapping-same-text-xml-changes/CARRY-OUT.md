# CARRY-OUT — GATE C

Written before any other narration. Every beat exists to make this sentence survivable.

## The line

> **Wrapping text in XML isn't a trick — it's speaking the shape Claude was
> trained to expect. Same words, matched structure, a sharper answer.**

## The wrong guess it defeats

That formatting is decoration: since the content is identical, the answer
should be too. It's the opposite — structure is a constraint the model
built strong expectations around during training, and text that matches
those expectations gets processed more coherently than text that doesn't.

## The secondhand test

*If someone repeats only this sentence in a meeting next week, is it still true?*

Yes — it compresses the one distinction that matters (structure as training
signal, not cosmetic) without smuggling in a claim about "prompt tricks" or
one specific tag schema.

## What it deliberately does not say

- Not "XML tags are magic" or a specific required schema — any consistent,
  field-labeled structure the model has seen at scale works the same way.
- Not a verdict on whether tagging is the "best" prompting technique — that's
  a design judgment (Teardown's lane), not Plain's.
- Not a claim about attention internals or tokenization — the reel stays at
  the level of training-distribution expectation, per the source's own
  exclusions.
