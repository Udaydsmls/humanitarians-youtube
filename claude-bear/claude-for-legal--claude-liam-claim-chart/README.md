# Claude, Claim Chart.

A claim chart breaks a legal claim into its separate elements, and each one
needs its own proof. Build one, and the easy read is to treat a full grid
as a strong case — every box has an entry, so every element must be
covered. But a filled cell only shows that a citation was found and pinned
to a page; it says nothing about whether that citation actually proves the
element. Watch the anchor: two elements from the same claim. "A locking
mechanism" turns up a citation straight to the product manual, page
twelve. "A temperature sensor" turns up nothing in the same manual — a
gap, flagged on purpose. A filled cell doesn't decide the case: a citation
can be weak, or cover only part of the element. And a gap doesn't decide
it either — it isn't proof the element fails, only proof no evidence has
turned up yet. Either way, the chart shows exactly where to look next.

## YOUR TURN

"Paste in the claim language, element by element, along with the accused
product's documentation. For each element, find the exact passage that
supports it, cite it, and flag any element with no citation as a gap —
don't guess to fill it in."

Why it's worth running: the exercise surfaces the same distinction the
reel is built around — a chart is only useful once you can tell its filled
cells from its gaps, not by how full it looks.

## Deliberately not claimed

This reel keeps the source Teardown sheet's real facts (the `claim-chart`
Anthropic Skill: builds or reviews an element chart, every cell pin-cited,
gap detection as the priority output) but re-registers the narration from
Teardown to Plain — explaining the mechanism, never judging the skill's
design. It never claims a gap means the claim fails, and never claims a
full chart proves infringement or a cause of action: a filled cell is a
found and pinned citation, not an adjudicated fact.
