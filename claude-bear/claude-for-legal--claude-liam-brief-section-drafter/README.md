## Description

Can Claude write your whole legal brief for you? Not quite — Anthropic's
brief-section-drafter skill drafts one section, in your case's own theory, and every
fact and case it cites still needs your check.

From Humanitarians AI: short, plain explanations of how Claude actually works, for a
general audience meeting Claude for the first time. Liam, in for Professor Bear.

In this one: what a Claude Skill actually is — a folder Claude reads before it works,
holding the full instruction set in one file; how the pipeline runs, step by step, no
branching unless a step says so; the exact constraint this skill drafts to (house style,
consistent with the case theory, every fact cited, every case checked, every argument
tied back to the theory); and the carry-out that matters: same spec in, same section out,
every time — but checking the facts, the cases, and anything outside that spec is still
the lawyer's job.

Try it yourself — the video ends with a paste-ready prompt for drafting your own next
brief section in Claude today.
