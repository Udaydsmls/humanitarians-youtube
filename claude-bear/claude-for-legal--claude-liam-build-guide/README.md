# Claude, Build Guide.

Claude picked up a skill called build-guide — did it actually learn
something new? No. A "skill" is a folder holding one file, SKILL.md, that
Claude reads before it starts and then follows step by step, in order.
Delete the folder and Claude forgets nothing, because there was nothing to
learn — it just stops following that one routine. That makes a skill a
specification, not a new power: the payoff is repeatable results, run after
run; the limit is anything the file never wrote down. And watching Claude
follow a skill exactly, or watching it improvise, proves nothing on its own
about whether the routine is good.
