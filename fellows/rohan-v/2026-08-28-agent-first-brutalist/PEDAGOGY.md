# PEDAGOGY — "Your Weekly Video, Handled." (hai / ai-explainer)

Narration sign-off record. The audience is a Humanitarians AI fellow who may
have never opened a terminal, and the reel fails if that person still doesn't
know what to do on Friday.

## The one thing this video has to land

**Ten steps exist. Seven belong to the agent. Three belong to you — and none of
the three is a command.** Everything else in the reel is in service of that
sentence, which is why it gets a dedicated beat (B10) rather than a closing line.

## Act structure

| | |
|---|---|
| B00 cold open with RESULT lines | ✓ ASK→RESULT at B00 — the ask lands answered, so the viewer knows the shape of the answer before the detail |
| B01 requirement before method | ✓ what is due comes *before* how to make it; a fellow who stops watching after 50s still knows the deliverable |
| B02–B06 the loop, in execution order | ✓ setup → plan → voice → review → formats. Each beat is one step, no step is described twice |
| B07–B09 submission, split by destination | ✓ the two-destination confusion is named explicitly at B07 and resolved by B09 |
| B10 verdict recap | ✓ the 7-vs-3 ledger — the thesis, restated as a shape |
| B11 "Your turn." handoff | ✓ a paste-ready prompt, read aloud |
| B12 title-restate outro | ✓ signed with the presenter's full name |

## ILLUSTRATE LAW

The Claude desktop UI appears at **B02 and B11 only** — the two beats where the
app itself is the subject. GitHub's surface appears at B07/B08 and Drive's at
B09, for the same reason. The remaining nine beats illustrate their concept
rather than showing an interface. No two consecutive beats share a visual
grammar.

## Register — Pragmatist, per `brands/hai.md`

- Leads with method, not motivation. ✓
- States the decision trigger. ✓
- **States where it fails / what it will not do.** ✓ — B05 is the whole beat:
  Claude cannot watch the video, so taste is not delegable. B09 is the second:
  the agent does not and should not upload to Drive. This is the required
  "when NOT to" and it is not softened.
- No personality tax, no academic hedging. ✓

## Vocabulary discipline

Every term a non-coder might not know is either avoided or defined **in the same
breath**:

| Term | How it is handled |
|---|---|
| beat sheet | defined on first use: "a numbered plan where every beat is one moment of the video" |
| fork / branch / pull request | deliberately **not** defined — B08 shows both routes visually and closes with "You don't need to know what a fork is." Teaching git here would be the wrong lesson |
| repository | used only as "the Humanitarians YouTube repository", in context |
| render / compile | avoided in narration entirely; the narration says "builds", "renders every visual" only where the picture carries the meaning |
| 4K, 16:9, 9:16 | spoken as "four K", "sixteen by nine", "nine by sixteen" so TTS reads them correctly |
| terminal / command line | used *as the thing you are avoiding* — the only technical words the reel leans on, because the promise depends on them |

## Friction — kept and removed

**Kept** (germane — the viewer should feel it):
- B05 makes the reviewer's job sound like work, because it is. Softening it
  would produce fellows who rubber-stamp previews.
- B08 names itself "the classic blocker" rather than pretending Git is simple.

**Removed** (extraneous at 4:14):
- How Kokoro/Manim/Remotion actually work — mechanism the fellow never touches.
- The `pantry/` and slate system — this reel has no slates, and a fellow using
  the agent conversationally will never hand-place a slot.
- Anything about publishing. The toolkit deliberately cannot publish, and a
  fellow's job ends at Drive.

## URL policy

No URL is spoken. All three appear on screen only, verbatim, held long enough to
read (B02 permission card, B07 footer, B09 footer). A read-aloud URL is unusable
to a listener, and reading this repository path aloud would also name a person
the narration is required to leave out.

## Length

254s (4:14) against a 3–5 minute brief. Every beat is between 8.1s and 31.5s;
the longest (B01) is the requirement itself, which is the one thing a fellow
cannot afford to half-hear.
